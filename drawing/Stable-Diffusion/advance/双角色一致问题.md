# 双角色一致问题
Stable Diffusion 能够通过多种技术方案有效解决同一画面中双角色一致性问题，且无需多次重复生成浪费成本。以下是具体实现方法及操作指南：

---

### 一、**角色特征固定技术**
#### 1. **LoRA模型精准控制**
通过训练或加载现成的LoRA模型，可固定角色核心特征（如发型、服饰、面部结构）。例如，在生成《最终幻想7》蒂法和爱丽丝同框画面时，可分别加载对应的LoRA模型：
```
正向提示词示例： 
(2girl:1.2), <lora:tifa_v2:1>, <lora:aerith_v1:1>, 分区控制...
```
- **优势**：角色细节保真度达90%以上，支持特征组合叠加
- **局限**：需预先训练或收集高质量LoRA模型（推荐Civitai平台下载）

#### 2. **IP-Adapter面部移植**
结合ControlNet的IP-Adapter FaceID技术，可将参考图面部特征移植到新生成角色。操作流程：
1. 上传参考角色正脸图至ControlNet单元
2. 选择`ip-adapter_face_id_plus`预处理器
3. 设置控制权重0.6-0.8，终止时机0.8-1.0
```yaml
ControlNet参数示例：
单元1类型：IP-Adapter
模型：ip-adapter-faceid-plusv2_sdxl
控制权重：0.7
```
- **效果提升**：面部特征相似度提高50%以上

---

### 二、**空间布局控制方案**
#### 1. **区域提示词分区法**
使用Regional Prompter插件实现物理空间分割：
```python
提示词结构：
[区域1: 0.0-0.5宽度] 角色A描述 + <lora:A>
[区域2: 0.5-1.0宽度] 角色B描述 + <lora:B>
```
- **参数设置**：
  - 分区权重比建议2:1（主角色权重更高）
  - 边缘羽化(Feather)设为0.1-0.3避免生硬过渡

#### 2. **Latent Couple蒙版控制**
通过坐标定位精确划分角色区域：
1. 设置分区方式为`1:2`（左右两等分）
2. 角色A定位`0:0`，角色B定位`0:1`
3. 启用Composable LoRA插件防止特征污染
```python
分区参数示例：
分区方式：1:2
分区位置：角色A(0:0), 角色B(0:1)
```

---

### 三、**骨骼与构图强化**
#### 1. **OpenPose骨骼绑定**
上传双人姿势参考图至ControlNet单元：
- 预处理器选择`openpose_full`
- 控制权重建议0-0.3（避免过度僵硬）
- 终止时机设为0.6-0.8保留AI创作空间

#### 2. **Lineart线稿引导**
通过线稿约束整体构图：
1. 绘制或生成场景线稿
2. 加载至第二个ControlNet单元
3. 选择`lineart_standard`预处理器
```yaml
ControlNet双单元配置示例：
单元0：OpenPose（骨骼控制）
单元1：Lineart（场景构图）
```

---

### 四、**工作流优化建议**
1. **硬件配置方案**：
   - 显存≥8GB：直接使用SDXL模型（如DreamShaper XL）
   - 显存≤6GB：采用SD1.5+LCM加速（生成速度提升3倍）

2. **参数黄金组合**：
   ```yaml
   采样器：DPM++ 2M Karras
   迭代步数：20-30步
   CFG值：5-7
   分辨率：1024x1024（SDXL） / 768x512（SD1.5）
   ```

3. **后期修复方案**：
   - 开启ADetailer面部修复（模型选`face_yolov8n.pt`）
   - 使用Ultimate SD Upscale放大至4K分辨率
