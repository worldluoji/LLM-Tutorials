# role
## 各角色的作用
System（系统）：
- 设定AI的行为和角色
- 提供上下文和指导
- 设置约束和规则
- 在整个对话中保持一致性

User（用户）：
- 代表人类的输入
- 提出问题或请求
- 提供具体内容

Assistant（助手）：
- AI的回复内容
- 执行任务的结果
- 对用户问题的回答

Function（函数）：
- 外部函数的调用结果
- 工具或API的返回数据
- 结构化数据

```py
# 一个完整的对话示例
messages = [
    # 设置AI的角色
    {"role": "system", "content": "你是一个专业的Python编程助手"},
    
    # 用户的问题
    {"role": "user", "content": "如何写一个列表推导式？"},
    
    # AI的回答
    {"role": "assistant", "content": "列表推导式的基本语法是：[表达式 for 变量 in 可迭代对象]"},
    
    # 用户的追问
    {"role": "user", "content": "能给我一个具体的例子吗？"},
    
    # AI的回答
    {"role": "assistant", "content": "例如：[x**2 for x in range(5)] 会生成 [0, 1, 4, 9, 16]"},
    
    # 如果需要调用外部函数
    {"role": "function", "name": "execute_code", "content": "[x**2 for x in range(5)]"}
]
```
