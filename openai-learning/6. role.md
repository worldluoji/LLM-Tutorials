# role
## 各角色的作用
System（系统）：
- 设定AI的行为和角色
- 提供上下文和指导
- 设置约束和规则
- 在整个对话中保持一致性

User（用户）：
- 代表人类的输入
- 提出问题或请求
- 提供具体内容

Assistant（助手）：
- AI的回复内容
- 执行任务的结果
- 对用户问题的回答

Function（函数）：
- 外部函数的调用结果
- 工具或API的返回数据
- 结构化数据

```py
# 一个完整的对话示例
messages = [
    # 设置AI的角色
    {"role": "system", "content": "你是一个专业的Python编程助手"},
    
    # 用户的问题
    {"role": "user", "content": "如何写一个列表推导式？"},
    
    # AI的回答
    {"role": "assistant", "content": "列表推导式的基本语法是：[表达式 for 变量 in 可迭代对象]"},
    
    # 用户的追问
    {"role": "user", "content": "能给我一个具体的例子吗？"},
    
    # AI的回答
    {"role": "assistant", "content": "例如：[x**2 for x in range(5)] 会生成 [0, 1, 4, 9, 16]"},
    
    # 如果需要调用外部函数
    {"role": "function", "name": "execute_code", "content": "[x**2 for x in range(5)]"}
]
```

## 示例2: 使用 function call
```py
import openai
import json

# 1. 定义可用的函数
def get_weather(location: str) -> dict:
    # 模拟天气API调用
    weather_data = {
        "temperature": 25,
        "humidity": 60,
        "condition": "晴天"
    }
    return weather_data

# 2. 定义函数描述
available_functions = [
    {
        "name": "get_weather",
        "description": "获取指定城市的天气信息",
        "parameters": {
            "type": "object",
            "properties": {
                "location": {
                    "type": "string",
                    "description": "城市名称"
                }
            },
            "required": ["location"]
        }
    }
]

# 3. 用户对话
messages = [
    {"role": "system", "content": "你是一个天气助手，可以帮助用户查询天气信息。"},
    {"role": "user", "content": "北京今天天气怎么样？"}
]

# 4. 调用API
response = openai.ChatCompletion.create(
    model="gpt-3.5-turbo",
    messages=messages,
    functions=available_functions
)

# 5. 处理函数调用
if response.choices[0].message.function_call:
    # 获取函数调用信息
    function_call = response.choices[0].message.function_call
    function_name = function_call.name
    function_args = json.loads(function_call.arguments)
    
    # 执行函数
    if function_name == "get_weather":
        weather_result = get_weather(function_args["location"])
        
        # 将函数结果添加到对话中
        messages.append({
            "role": "function",
            "name": function_name,
            "content": json.dumps(weather_result)
        })
        
        # 让AI解释结果
        response = openai.ChatCompletion.create(
            model="gpt-3.5-turbo",
            messages=messages
        )
        
        print(response.choices[0].message.content)
```
这实际就是：
- User是客户，提出需求
- Assistant是客服，理解需求并决定使用什么工具
- Function是具体的工具，执行实际任务
- 最后Assistant解释工具返回的结果

通过Function Call，AI可以：
- 访问外部数据
- 执行具体操作
- 获取实时信息
- 提供更实用的服务
