# 橘猫日常生活视频的制作方法

## 第一步：图片生成 

自己构建一个日常琐碎事，比如做饭，那么我们可以分成四个镜头去制作

菜市场买菜/骑电动车回家/厨房切菜或炒菜/桌前吃饭

那么我们根据四个分镜头去写生成图片所需要的的提示词，写提示词其实很简单，通过文字将画面风格，镜头视角，

分镜一提示词：
```
写实风格，全景，全身，侧面，一只巨大的胖橘猫，站在菜摊前，一只手提着竹编篮子，篮子装着少量胡萝卜，另一只手在菜摊前拿起玉米，背景是一个人来人往的菜市场，市场中摆放着各种蔬菜摊，有玉米，有上海青等，色彩丰富，充满了生活气息，周围有店铺和灯光
```
很多小伙伴不会写提示词，可以使用deepseek去写。

打开各类图片创作AI，比如Midjourney（建议用MJ6.0真实质感），我们把提示词放进去，开始生成，不满意可以持续换，一直到自己满意为止。

---

## 第二步：图生视频
我们选择一张自己满意的图片，打开视频生成的AI， 比如即梦AI、海螺AI等，点击图生视频，输入镜头位置和的动作提示词，比如：
```
固定镜头拍摄，橘猫在摊位前拿起玉米放进篮子里
```
选择视频s2.0。当然，如果追求更生动的视频而且不缺积分，可以选择视频s2.0pro。

分镜一就完成了，接下来的分镜都是一样的操作。


---

## 第三步：重复步骤一和步骤二，完成所有分镜
分镜2:
```
写实风格，全景，全身，侧面，一只巨大的胖橘猫头上戴着头盔骑着电动自行车在马路上，电动自行车前的篮子里放着胡萝卜和玉米。
```

分镜3:
```
写实风格，全景，全身，正面，一只巨大的胖橘猫身穿蓝白条纹围裙低头站在灶台前，左手抓胡萝卜，右手拿菜刀在案板上切块，身旁的高压锅冒着热气，背景是一个摆满厨具的厨房，充满生活气息。
```

分镜4:
```
写实风格，全景，全身，正面，一只巨大的胖橘猫一脸开心坐在白色桌子前左手端着一碗冒着热气的白米饭，右手拿着筷子夹菜，桌子上有一盆冒着热气的玉米粒炒胡萝卜丝，背景是一个明亮的客厅。
```
抽卡选图，然后写视频提示词：一脸开心大口吃着饭菜。


---

## 第四步：配音
现成的可以使用魔音工坊。也可以使用阿里通义提供的API。前者使用更简单，后者更省钱。

---

## 第五步，去除水印
- 方案1: 通过剪映等工具去除水印。
- 方案2: 在生成视频时，调用阿里的大模型API生成，这样生成出来的视频没有水印：https://bailian.console.aliyun.com/?tab=api#/api/?type=model&url=https%3A%2F%2Fhelp.aliyun.com%2Fdocument_detail%2F2867393.html
