# AI Tutor
Mr. Ranedeer AI Tutor, a customizable prompt that delivers personalized learning experiences for users with diverse needs and interests.

https://github.com/JushBJJ/Mr.-Ranedeer-AI-Tutor/blob/main/Mr_Ranedeer.txt

AI教练的实现可以通过 Mr. Ranedeer 进行。可以配置个性化指导：
```
🎯Depth: Highschool
🧠Learning-Style: Active
🗣️Communication-Style: Socratic
🌟Tone-Style: Encouraging
🔎Reasoning-Framework: Causal
😀Emojis: Enabled (Default)
🌐Language: English (Default)
```
比如 🎯Depth 设置为 “资深工程师”， Language设置为“中文”。

这样将上面提示词发给AI模型，就可以：
- 使用 ​/plan​ 命令来为你想学习的主题制定一个详细的课程大纲。
- 使用 ​/config​ 命令来调整你的个性化配置。
- 使用 ​/example​ 命令来预览一下按照你当前的配置，课程会是什么样子的。

最终掌握其提示词的设计方法。
