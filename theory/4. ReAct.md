# ReAct
ReAct: Re=推理（Reasoning），Act=行动（Acting）

ReAct 思想会让大模型把大问题拆分成小问题，一步步地解决，每一步都会尝试调用外部工具来解决问题，并且还会根据工具的反馈结果，思考工具调用是否出了问题。如果判断出问题了，大模型会尝试重新调用工具。这样经过一系列的工具调用后，最终完成目标。

基本组成：
- Reasoning（推理）：分析问题、制定计划
- Acting（行动）：执行具体步骤
- 循环往复：根据执行结果调整计划

工作流程：
```
思考（Thought）→ 行动（Action）→ 观察（Observation）→ 思考（Thought）...
```

具体例子：
假设要解决"帮我写一个Python爬虫程序"这个问题：
```
Thought: 首先需要确定爬取的目标网站和所需数据
Action: 询问用户具体要爬取哪个网站
Observation: 用户回答"爬取新闻网站"
Thought: 需要确定使用requests还是selenium
Action: 选择使用requests库，因为新闻网站是静态的
Observation: 开始编写代码
Thought: 需要添加错误处理和反爬虫措施
Action: 添加try-except和请求头
...
```
