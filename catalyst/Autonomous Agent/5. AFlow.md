# AFlow
MetaGPT 团队是一个非常有探索精神的团队，他们一个最新的重大研发成果是所谓的 AFlow。这个专业术语来自于一篇发表在 arXiv 网站上的论文，标题为 [AFLOW: AUTOMATING AGENTIC WORKFLOW GENERATION](https://arxiv.org/abs/2410.10762)（自动化智能体工作流生成）

AFlow 这个领域目前还处于研究阶段，因此有很强的学术性。但是 AFlow 已经引起了业界的广泛关注。

## AFlow 致力于解决的问题
简单的工作流确实可以这样手工实现，对于复杂的工作流来说，完全依赖手工实现的工作流，很有可能并非是最优的工作流。为了达到相同的业务目标，可能还会有更优的工作流。

开发者非常需要有一套工具和开发框架来开展探索。于是就有了第二种实现工作流的方式，那就是针对要达到的业务目标自动生成工作流，并且对自动生成的多种工作流开展性能评估和优化，选择出其中最优的工作流。

一种很自然的思路是充分挖掘基础 LLM 的能力，利用 LLM 来为我们做分析和计划，自动生成工作流。AFlow 正是一套利用 LLM 来自动生成工作流，并且对工作流做性能评估和优化，得到最优工作流的开发框架。

在未来的 MetaGPT 1.0 版本中，AFlow 将会成为系统的一个核心的组件。与目前 0.8.1 版中仅能通过手工方式实现简单的工作流相比，MetaGPT 1.0 将会提供强大得多的对于复杂工作流的支持。
