# Maintain and Refactor
挑战：
- 线上问题诊断：突如其来的异常，如何在海量的日志和复杂的代码调用链中，快速定位根因？
- 技术债偿还：当初为了快速上线而写下的“临时”代码，现在成了新功能开发的瓶颈，如何安全地、大规模地进行重构？
- 知识传承断裂：项目经过几代开发者的维护，文档早已过时，新成员如何快速理解一个“黑盒”般的遗留模块？

在面对“遗留系统”——即那些已经上线、包含大量历史代码和技术债的项目时，AI 的角色将发生一次关键的升维，它需要更多地扮演“智能分析师”和“安全架构师”的角色。
- 从“确定性”到“不确定性”：面对的不再是清晰的规范，而是充满了未知 Bug、隐性依赖和过时注释的存量代码。
- 从“创造”到“理解与改造”：核心任务不再是“从无到有”，而是“在深度理解现有复杂度的基础上，进行最小化、最安全的变更”。

这正是我们之前学习的上下文注入（@）、安全基石（--checkpointing）和编程接口（headless）等高级能力大放异彩的舞台。

---

## 场景一（问题诊断）：扮演“根因分析专家”，智能调试线上报错
假设 Web 服务上线运行了一段时间后，监控系统突然告警，捕获到了一个异常。运维同学将相关的日志和堆栈跟踪（stack trace）发给了你。

我们需要分析异常，找到对应的代码，本地复现和修复。这个过程可能需要半小时甚至更久。现在，让我们看看 AI 如何将这个过程压缩到几分钟。

准备 Prompt：我们的 Prompt 需要清晰地告诉 AI 它的角色、任务、上下文来源和输出要求。
```
PROMPT="""
你现在是一位顶级的Node.js语言诊断工程师，一个“代码验尸官”。

我将通过标准输入(stdin)为你提供一段线上服务的异常日志。同时，我会用`@`指令为你提供相关的源代码文件。

你的任务是：
1.  **精准定位：** 根据异常的堆栈跟踪，找出导致崩溃的确切代码行和变量。
2.  **根因分析：** 深入分析代码逻辑，解释为什么那个变量会是null。
3.  **修复建议：** 提供具体的、可直接应用的Nodejs代码修复方案。
4.  **预防措施：** 提出1-2条可以从机制上预防此类问题的建议。

请以Markdown格式，输出一份结构清晰的根因分析报告。
"""
```

执行命令：现在，我们用一条命令，将日志、代码和指令全部“喂”给 AI
```bash
cat error.log | claude -p "$PROMPT" @cmd/issue2mdweb/main.js converter/converter.js > root_cause_analysis.md
```
片刻之后，root_cause_analysis.md 文件就生成了。AI 像一个经验丰富的老手，在几分钟内就完成了一次高质量的、从定位到预防的完整诊断。

## 场景二（安全重构）：扮演“外科手术医生”，安全地进行大规模重构
有时，我们需要对代码进行重构，一些重构的风险很高，一旦出错，可能会破坏整个核心功能。这正是 Checkpointing（检查点）机制的最佳舞台。

你可以让AI进行重构，当发生错误时，回滚到上一个Checkpointing，再调整prompt，重新开始，知道TDD测试用例全部通过。

可见 Checkpointing 在复杂、高风险重构任务中，作为“无限次试错的安全网”的巨大价值。

## 场景三（知识库同步）：扮演“技术文档工程师”，让文档永不过时
当我们的项目经过了多次迭代，我们甚至可能已经添加了 --format、--output 等新的命令行参数。但是，项目根目录下的 README.md，还停留在最初的版本。文档与代码已经严重脱节。

让我们来创建这个指令。在 ./.claude/commands/ 目录下，创建 update-docs.md：
```
---
description: 扫描整个项目，并更新或重新生成README.md文档。
model: opus
---

你是一位优秀的技术文档工程师。请全面扫描当前目录（`@.`）下的所有文件，特别是 `pakcage.json`、`Makefile` 以及 `cmd/` 目录下的 `main.js`，以理解项目的最新状态。

然后，请为项目，重新生成一份完整、清晰、与当前代码完全同步的 `README.md` 文件内容。

这份README必须包含以下部分：
1.  **项目简介 (Overview)**
2.  **核心特性 (Features)**
3.  **安装指南 (Installation)**
4.  **使用方法 (Usage):** 必须包含所有命令行参数的详细说明和示例。
5.  **构建方法 (Building from Source):** 必须引用`Makefile`中的命令。
```
现在，我们只需在 Claude Code 中执行一个简单的命令：
```
/update-docs
```
这个场景，展示了 AI 在逆向工程和知识整理方面的强大能力。它能将分散在代码、构建脚本和依赖文件中的隐性知识，“反向编译”为人类易于理解的显性文档，彻底解决了“文档即负债”的千古难题。
