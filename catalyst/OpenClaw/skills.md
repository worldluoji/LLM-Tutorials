### 🚀 如何安装？
你可以通过官方 CLI 工具 `clawhub` 来安装。示例如下：
```bash
# 1. 安装 CLI 工具（如果还没装）
npm i -g clawhub

# 2. 安装单个技能，例如 Tavily Search
clawhub install tavily-search

# 3. 一次性更新所有已安装的技能
clawhub update --all
```
> 安装后，技能通常会在下一次与 OpenClaw 交互时自动加载生效。

建议从**安全（Skill Vetter）**和**搜索（Tavily Search）**开始安装，这两款能立刻让你感受到功能的显著提升。如果对某个特定技能的具体用法感兴趣，可以随时告诉我。
