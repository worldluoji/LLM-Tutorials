# crud 示例
以下是一个 Qdrant 增删查改（CRUD）的 Python 示例：

---

**完整代码示例**

```python
from qdrant_client import QdrantClient
from qdrant_client.http import models
import numpy as np

# 初始化客户端（替换为实际地址和API Key），通过 Docker 或二进制文件本地启动 Qdrant 时，默认​​不启用认证​​，客户端连接无需提供 API 密钥。生产或者Qdrant Cloud一定要家api_key。
# 若手动为自部署的 Qdrant 配置了认证，需通过环境变量启用密钥验证：# 启动 Qdrant 时设置 API_KEY（此处示例密钥为 "your-api-key"）：docker run -p 6333:6333 -e QDRANT__SERVICE__API_KEY=your-api-key qdrant/qdrant
client = QdrantClient(host="localhost", port=6333, api_key="your-api-key")

# -------------------- 1. 创建集合 --------------------
collection_name = "demo_products"
client.recreate_collection(
    collection_name=collection_name,
    vectors_config=models.VectorParams(size=512, distance=models.Distance.COSINE),  # 正式场景常用512维
)

# -------------------- 2. 插入数据（Create） --------------------
# 示例中的向量为随机生成的假数据，实际需要模型生成！
fake_vectors = {
    1: np.random.rand(512).tolist(),  # 模拟512维向量（真实场景需规范生成）
    2: np.random.rand(512).tolist(),
}
points = [
    models.PointStruct(
        id=1,
        vector=fake_vectors[1],  # 此处使用假数据仅作演示
        payload={"name": "无线耳机", "price": 599, "brand": "XM"},
    ),
    models.PointStruct(
        id=2,
        vector=fake_vectors[2],
        payload={"name": "智能手表", "price": 1499, "brand": "AP"},
    ),
]
client.upsert(collection_name=collection_name, points=points, wait=True)

# -------------------- 3. 查询数据（Read） --------------------
query_vector = np.random.rand(512).tolist()  # 这里也应为真实用户/商品的向量
hits = client.search(
    collection_name=collection_name,
    query_vector=query_vector,
    limit=3,
    with_payload=True,
)

# -------------------- 4. 更新数据（Update） --------------------
# 更新ID=2的元数据（保留原向量）
client.set_payload(
    collection_name=collection_name,
    payload={"price": 1299, "discount": 0.2},
    points=[2],
)

# -------------------- 5. 删除数据（Delete） --------------------
client.delete(collection_name=collection_name, points_selector=[1])
```

---

**关键补充：向量（Vector）的实战应用**
1. **示例中的假数据问题**
代码中使用的向量是 `np.random.rand(512)` 生成的随机值，仅用于演示结构。真实场景中需避免随机数据，否则无法表达语义相似性。

2. **实际应用如何生成向量**
- 文本数据：使用 NLP 模型生成嵌入向量  

  ```python
  # 示例：用 Sentence-BERT 生成文本向量
  from sentence_transformers import SentenceTransformer
  model = SentenceTransformer('paraphrase-multilingual-MiniLM-L12-v2')
  text = "降噪无线耳机"
  text_vector = model.encode(text).tolist()  # 得到768维向量（需对齐集合维度）
  ```

- 图像数据：使用 CNN 模型提取特征  

  ```python
  # 示例：用 ResNet50 生成图片向量
  from tensorflow.keras.applications.resnet50 import ResNet50, preprocess_input
  from tensorflow.keras.preprocessing import image
  model = ResNet50(weights='imagenet', include_top=False, pooling='avg')
  
  img_path = "headphone.jpg"
  img = image.load_img(img_path, target_size=(224, 224))
  x = image.img_to_array(img)
  x = preprocess_input(x)
  img_vector = model.predict(np.expand_dims(x, axis=0))[0].tolist()  # 2048维向量
  ```

- 其他数据：  

  - 语音：Wav2Vec、HuBERT  

  - 视频：3D CNN、时序模型  


3. **向量的标准化处理**  
如果使用余弦相似度，需对向量归一化（L2标准化）：  
```python
from sklearn.preprocessing import normalize
vector = normalize([vector], norm="l2")[0].tolist()  # 转换为单位向量
```

4. **向量维度对齐**
创建的集合维度（如`size=512`）必须与生成的向量实际维度严格一致。

**注意事项**
1. 模型选择  
   根据场景选择预训练模型，例如：
   - 文本搜索：`BERT`、`Sentence-BERT`  

   - 图像检索：`ResNet`、`CLIP`  

   - 跨模态：`CLIP（图文混合）`、`ALBEF`


2. 混合搜索优化  
   ```python
   # 结合元数据过滤：搜索价格低于1500的相似商品
   hits = client.search(
       query_filter=models.Filter(
           must=[models.FieldCondition(key="price", range=models.Range(lt=1500))]
       )
   )
   ```

3. 生产环境建议  
   - 数据预处理：去噪、去除重复数据  

   - 向量版本管理：更换模型时需重建集合  

   - 性能监控：关注延迟、召回率等指标
